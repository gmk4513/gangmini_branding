# 화면 캡처

여기에 캡처 이미지를 넣는다. 아직 비어 있음 — 직접 찍어서 채울 것.

## 왜 필요한가

1. **OG 이미지** — 링크 공유 시 썸네일. 지금 `og:image` 가 비어 있어서 카카오톡·인스타에
   링크를 올리면 썸네일이 안 나온다. `home.png` 를 1200×630 으로 잘라 쓰면 된다
2. **README 상단 미리보기**
3. **회귀 확인용 기준** — 레이아웃을 고친 뒤 이전 캡처와 비교

## 어떤 크기로

레이아웃이 화면 비율에 따라 달라지므로 **최소 두 가지**로 찍는다.

- **세로로 긴 폰** (예: 390×844) — 가장 빡빡한 조건. 겹침은 여기서 먼저 터진다
- **데스크톱** (창 높이 900 안팎) — 실제 폭은 `62vh` 로 제한된다

크롬 개발자도구 > 기기 툴바(Ctrl/Cmd+Shift+M) 에서 크기를 지정하고,
기기 툴바 오른쪽 메뉴의 "Capture screenshot" 을 쓰면 브라우저 UI 없이 깔끔하게 나온다.

## 확인할 것

캡처하면서 아래를 같이 본다. 전부 계산으로만 맞춰둔 것들이라 실물 확인이 안 됐다.

- [ ] 홈: 제목 2줄 / 브금 버튼 / 게임 시작 버튼이 서로 안 겹치는가
- [ ] 홈: 두 캐릭터 말풍선이 서로 안 겹치는가 (긴 대사일 때)
- [ ] 게임: 블록이 배경과 구분되는가 (밝기 차 확보했는지)
- [ ] 게임: 다음 블록이 왼쪽인지 오른쪽인지 한눈에 읽히는가
- [ ] 결과: 싸우는 캐릭터가 배경 속 노인들과 안 겹치는가
- [ ] 결과: '기록 저장' 글씨가 검정으로 보이는가 (저장을 한 번 누른 뒤에도)
