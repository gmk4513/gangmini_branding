# 학사모 비프리의 아파트 건설현장

로보트보다 빠르게 아파트를 몇 층까지 지을 수 있을까 — 2버튼 아케이드 웹게임.

빌드 도구 없음. 정적 파일 그대로 올리면 동작한다.

## 바로 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://` 로 직접 열지 말 것. 브라우저가 오디오와 일부 캔버스 동작을 막는다.

## 조작

| | 터치 | 키보드 |
|---|---|---|
| TURN — 방향을 바꿔 한 칸 | 화면 왼쪽 아래 버튼 | 스페이스 |
| CLIMB — 보던 방향으로 한 칸 | 화면 오른쪽 아래 버튼 | → |

다음 블록이 없는 쪽으로 가면 즉시 종료. 위쪽 게이지는 로봇과의 거리이고, 가만히 있으면 줄어든다.

## 배포

폴더를 통째로 올리면 끝이다.

```
gangmini.com/game/
├── index.html
├── css/
├── js/
└── assets/
```

Netlify / Vercel / GitHub Pages / 기존 웹서버 어디든 정적 호스팅이면 된다.

**iframe으로 박을 경우** — `index.html` 이 `100vh` 를 쓰므로 iframe 높이를 명시해야 한다.
세로로 긴 비율(가로:세로 ≈ 0.5)이 가장 잘 맞는다.

## 순위표

모든 사용자가 같은 순위표를 본다. 기록은 Fly.io 에 올려둔 내 Node 서버에 저장된다
(`https://bamti-bomb.fly.dev/api/scores/bfree`).

`js/leaderboard.js` 의 `MODE` 를 `'local'` 로 바꾸면 서버 없이 기기별 저장으로 돌아간다.
개발할 때 쓴다. 자세한 것은 `CLAUDE.md` 참고.

## 용량

| | |
|---|---|
| 스프라이트 | 약 1.5 MB |
| 배경 | 약 390 KB |
| 브금 (110초, 96kbps) | 약 1.3 MB |

첫 로딩이 무겁게 느껴지면 브금 비트레이트를 낮추거나 구간을 줄이면 된다.

## 코드를 고치기 전에

`CLAUDE.md` 를 먼저 읽을 것. 튜닝 상수의 의미, 좌표계 규칙, 그리고
**깨뜨리면 화면이 안 보이거나 버튼이 안 눌리는 네 가지 함정**이 정리되어 있다.
전부 실제로 한 번씩 겪었던 것들이다.
