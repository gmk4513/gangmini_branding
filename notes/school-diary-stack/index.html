내 프로젝트 스택 Expo React Native RevenueCat Vercel SQLite 2026.10.02

초등학교 때 쓰던 그림일기·독후감·급식표를 그 양식 그대로 옮긴 iOS/Android 앱이다. 혼자 만들어 두 스토어에 올렸고, 구독 결제가 붙어 있다. 여기서는 무엇을 왜 골랐는지를 적는다. 기능 설명이 아니라 선택의 기록이다.

전체 그림

앱 — Expo / React Native

혼자 만들고 두 스토어에 올려야 했다. 네이티브를 두 벌 쓰면 끝나지 않는다. Flutter도 후보였지만 Expo의 빌드·배포 자동화가 결정적이었다. 맥이 없어도 클라우드에서 iOS 빌드가 나오고, 명령 한 줄로 스토어까지 올라간다. 

eas build -p android --profile production
eas submit -p android --profile production

대가도 있다. 네이티브 모듈이 필요하면 expo-* 패키지가 있느냐가 먼저고, 없으면 직접 만들어야 한다. 이 앱에서도 줄공책 입력은 기성품으로 안 돼서 Swift와 Kotlin으로 모듈을 하나 썼다.

Skia를 쓴 이유

크레파스 질감은 이미지로 흉내 낼 수 없다. 획이 겹치는 곳마다 입자가 다르게 쌓여야 한다. 그래서 셰이더를 직접 쓸 수 있는 Skia를 얹었다. 이 앱에서 기술적으로 가장 비싼 부분이고, 동시에 사람들이 가장 먼저 알아보는 부분이다.

데이터 — 서버가 없다

회원가입이 없고 모든 기록은 기기의 SQLite에만 있다. 서버에 사용자 데이터를 두지 않았다.

얻은 것잃은 것
서버 비용 0원기기를 바꾸면 백업·복원을 직접 해야 한다
유출될 데이터가 없다여러 기기에서 같이 못 쓴다
개인정보 신고가 단순해진다통계를 볼 수 없다

일기는 사람이 쓰는 글 중 가장 내밀하다. "우리 서버에 없다"고 말할 수 있는 쪽이 이 앱에서는 기능 하나보다 값지다고 봤다.

수익화 — 돈이 도는 순서

설치하면 7일 동안 전부 열린다. 결제 정보를 넣지 않아도 쓸 수 있다. 이 7일은 스토어 기능이 아니라 앱이 직접 센다. 설치 시각을 기기에 적어두고 비교한다. 7일이 지나면 새 기록을 쓸 때 구독 화면이 뜬다. 이미 쓴 기록은 계속 보고 내보낼 수 있다.

RevenueCat을 왜 끼웠나

스토어 결제는 "샀다"에서 끝나지 않는다. 영수증이 진짜인지 확인해야 하고, 갱신·해지·환불·기기 변경을 계속 따라가야 한다. 이걸 직접 하려면 서버와 두 스토어의 API를 붙들어야 한다. 서버를 안 두기로 한 결정과 정면으로 부딪친다.

RevenueCat은 그 중간을 대신 서준다. 앱은 "이 사람 프리미엄이야?"만 묻는다. 일정 매출까지 무료이고, 그 위로는 매출의 일부를 가져간다. 즉 안 벌면 안 내는 비용이라 혼자 시작할 때 유리하다.

AI — 서버가 딱 하나 있는 이유

일기를 저장하면 선생님 말투의 한두 문장이 붙는다. 이걸 만들려면 Anthropic API를 부르는데, API 키를 앱에 넣을 수는 없다. 앱 번들은 전부 뜯어볼 수 있다. 예외 없다. 그래서 Vercel에 함수 하나만 뒀다. 이 앱에서 서버라고 부를 만한 건 이것뿐이다.

그 함수가 하는 일은 셋이다.

  • 키를 숨긴다
  • 글의 분위기를 normal / heavy / crisis로 나눈다
  • 받은 글을 저장하지 않고 버린다

두 번째가 핵심이다. 일기는 힘든 날에 더 많이 쓰인다. "다 그만두고 싶다"에 "오늘도 즐거웠구나!"가 붙으면 그건 위로가 아니라 무시다. 그래서 분류를 한 단계 두고, 심각한 신호에는 한마디를 만들지 않고 도움받을 곳을 안내하는 화면으로 넘긴다. 기능이 아니라 최소한의 책임에 가깝다.

정리 — 왜 이 조합인가

선택이유
Expo혼자서 두 스토어. 빌드·제출 자동화가 결정적
SQLite서버 비용 0. 유출될 데이터가 없다
Skia크레파스 질감은 이미지로 흉내 낼 수 없다
RevenueCat구독 생애주기를 서버 없이 넘긴다
Vercel 함수API 키를 가리는 최소한의 서버

관통하는 기준은 하나다. 혼자 감당할 수 있는 크기로 유지한다. 서버를 늘리면 비용이 늘고, 비용이 늘면 멈추게 된다. 그래서 서버가 꼭 필요한 곳(키 숨기기)에만 두고 나머지는 전부 기기 안이나 남의 서비스에 맡겼다.

이어서 적을 것

  • RevenueCat 없이 직접 영수증을 검증하면 무슨 일이 생기나
  • 스토어 수수료 15% / 30%는 어떻게 갈리나
  • 서버리스 함수는 어디에 쓰고 어디에 쓰면 안 되나
